# ROOTBOUND · 로그 퍼즐 프로토타입

Vue와 JavaScript로 구현한 퍼즐 전투 로그라이크입니다. 8층의 분기 경로를 탐험하며 파티를 영입·강화하고, 증강을 조합해 마지막 보스를 쓰러뜨립니다.

## 실행

Node.js 22.12 이상 또는 24 LTS를 사용하세요.

```sh
npm install
npm run dev
```

터미널에 표시되는 주소를 열면 됩니다. 모바일은 PC와 같은 Wi-Fi에 연결한 뒤 터미널의 Network 주소로 접속하세요. Windows 방화벽이 묻는 경우 사설 네트워크의 개발 서버 접근을 허용해야 합니다.

```sh
npm run build    # dist/에 정적 배포 파일 생성
npm run preview  # 빌드 결과 확인
npm test         # 퍼즐·전투 공식·경로 엔진 검사
```

브라우저 통합 검사는 `npx playwright install chromium`으로 Chromium을 설치한 뒤 `npm run test:browser`로 실행합니다. 데스크톱과 모바일 환경에서 마우스·터치·키보드 입력, 전투 보상, 증강, 승패 및 파티 교체를 확인합니다.

## 조작

- PC 마우스: 드롭을 누른 채 움직이고 놓으면 공격합니다.
- PC 키보드: 보드에 초점을 맞추고 방향키/WASD로 커서 이동 → Space/Enter로 잡기 → 방향키/WASD로 드롭 이동 → Space/Enter로 놓기. Escape도 현재 움직임을 확정합니다.
- 모바일: 터치 드래그만 지원합니다. 터치 기기에서는 키보드 입력을 받지 않습니다.
- 첫 드롭 이동부터 6초 제한 시간이 시작됩니다. 가로·세로 3개 이상 매치, 낙하, 추가 콤보를 판정합니다.
- 전투 중 동료 카드를 누르면 같은 속성 드롭 5개를 생성합니다. 스킬은 4턴 대기 후 다시 사용할 수 있습니다.

## 탐험 규칙

일반 전투는 몬스터 영입·능력치 강화·회복 중 하나를 보상으로 줍니다. 정예 전투는 성장 보상에 증강 선택까지 추가됩니다. 제단은 증강, 쉼터는 회복 또는 수련, 유적은 체력을 대가로 한 증강 또는 소량 회복을 제공합니다. 파티는 최대 6명이며 가득 차면 교체할 수 있습니다.

파티에 있는 속성만 공격합니다. 불→숲→물→불, 빛↔어둠은 피해 2배이고 불·숲·물의 역상성은 0.5배입니다. 콤보마다 기본 피해가 25% 증가합니다. 모든 성장은 회차 한정이며, 새로고침하면 초기화됩니다.

## 파일 구성

- `src/game.js`: 순수 JavaScript 퍼즐·전투·경로 엔진과 콘텐츠 정의
- `src/useGame.js`: 회차 상태, 보상, 입력 및 애니메이션 흐름
- `src/App.vue`: 화면 템플릿
- `src/style.css`: 반응형 화면과 보드 스타일
- `tests/game.test.js`: Node 내장 테스트

원작의 상세 피해 공식, 리더/각성 시스템, 영구 성장, 저장, 음향은 이번 프로토타입에 포함하지 않습니다. 폰트만 외부 Google Fonts를 선택적으로 사용하며, 게임은 별도 서버나 계정 없이 동작합니다.
